A little introduction

Engineering with curiosity.

I enjoy moving between technologies, solving practical problems, and owning the result from first idea to final deployment.

I'm a Full-Stack Developer focused on building practical, maintainable web applications. I work across the application lifecycle: backend logic, database design, APIs, frontend experiences, integrations, automation, and deployment.

AI is a core part of my development workflow. I use AI coding assistants and agentic tools to explore unfamiliar technologies, work across different frameworks, prototype faster, debug, and iterate. I stay responsible for architecture decisions, understanding the code, reviewing generated changes, testing, and the final result.

I prefer choosing the right tools for each problem instead of forcing every project into the same stack.
