## 🧑‍💻 About Me

I'm a **Full-Stack Developer** who enjoys turning ideas into reliable, usable software. I work across the application lifecycle: backend architecture, APIs, databases, frontend experiences, integrations, automation, and deployment.

AI is a major part of how I build software. I use AI assistants and agentic workflows to move across frameworks, investigate unfamiliar codebases, prototype, debug, and iterate faster. I still take ownership of the engineering: understanding the implementation, making technical decisions, reviewing generated code, and validating the result.

- ⚡ Building end-to-end web applications and developer tools.
- 🧩 Comfortable moving between frameworks and layers of the stack.
- 🤖 Using AI-assisted workflows as an engineering multiplier, not a substitute for judgment.
- 🔍 Interested in automation, integrations, real-time systems, and clean implementation.
