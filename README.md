## Selected Projects

### [WatchTogether](https://github.com/naserme/watchTogether)
A real-time watch-party application that synchronizes video playback between participants. Includes a Node.js and WebSocket server, plus a Cloudflare Workers implementation using Durable Objects.

### [SMS Panel Manager](https://github.com/naserme/sms-panel-manager)
A Laravel 12 application for managing SMS activity across multiple websites, with message reports, cost tracking, dashboards, and extensible SMS-provider integration.

### [Chrome Password Sync](https://github.com/naserme/chrome-password-sync)
An experimental Python utility for merging encrypted saved-login records between local Chrome profiles on Windows. Includes dry-run mode, conflict reporting, and SQLite backups. It is intended for careful testing with disposable profiles before use with real data.

### [Car Valuation Engine](https://github.com/naserme/Car-Valuation-Engine)
A Python project that collects car-listing data, stores and prepares it for analysis, and trains a machine-learning model to estimate vehicle prices.
